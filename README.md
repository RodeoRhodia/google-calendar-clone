# Google Calendar Clone

A fully-featured Google Calendar clone built with React 19, TypeScript, and Tailwind CSS 4. This is a learning project for exploring advanced React concepts.

**Live Demo:** https://google-calendar-clone-ten.vercel.app/

## Features

- **Monthly Calendar View** - Navigate between months with an intuitive interface
- **All-Day Events** - Create events that span entire days
- **Timed Events** - Schedule events with specific start and end times
- **Event Management** - Edit and delete events with ease
- **Responsive Design** - Clean, modern UI that matches Google Calendar's aesthetic

## Tech Stack

- **React 19** with TypeScript
- **Vite 7** with SWC for fast refresh
- **Tailwind CSS 4**
- **date-fns** for date manipulation

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
